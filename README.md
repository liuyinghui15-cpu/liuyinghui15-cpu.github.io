# Yinghui Liu — Personal Archive

A responsive editorial homepage for GitHub Pages: a personal masthead, an annotated group portrait, album covers, a film contact sheet, and coffee print studies.

## Local preview

Open `index.html` directly in a browser, or serve this folder locally:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish folder

This folder contains only the files required by the page:

- `index.html`
- `README.md`
- `assets/albums/` — album artwork used on the page
- `assets/film/` — film photographs used on the page
- `assets/coffee-prints/` — coffee artwork used on the page
- `assets/portrait-middle-collage-torn.webp` — main portrait, with PNG fallback
- `assets/fonts/` — local display fonts and their license

All photographs and album artwork were supplied by the site owner. Confirm public distribution rights before publishing this folder.
